# 🍕 Pizza Sales Analysis Dashboard

An interactive Power BI dashboard analyzing a full year of pizza sales data, built to uncover sales trends, top-performing products, and business insights.

## 📊 Overview

This project connects to **MS SQL Server** as the data source and uses **Power BI** to visualize and analyze pizza sales performance across categories, sizes, and time periods.

- **Total Revenue:** $817.86K
- **Total Orders:** 21,350
- **Total Pizzas Sold:** 49,574
- **Avg Order Value:** $38.31
- **Avg Pizzas Per Order:** 2.32

## 🛠️ Tools Used

- **MS SQL Server** – Data storage and querying
- **Power BI** – Data modeling, DAX calculations, and dashboard design


## 🔍 Key Insights

- **Peak sales days:** Orders are highest on weekends, especially Friday and Saturday evenings.
- **Peak sales months:** July and January recorded the highest order volumes.
- **Category performance:** Classic category pizzas contribute the most to total sales and orders.
- **Size performance:** Large-size pizzas drive the highest sales volume.
- **Top performer:** The Thai Chicken Pizza generates the highest revenue, while The Classic Deluxe Pizza leads in total quantity sold and total orders.
- **Lowest performer:** The Brie Carre Pizza ranks lowest across revenue, quantity, and total orders.
